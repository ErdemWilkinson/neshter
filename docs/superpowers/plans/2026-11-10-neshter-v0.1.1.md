# Neşter v0.1.1 (post-audit fix release) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the v0.1 backend fast on ordinary CPUs, statistically honest, exact on every supported family, safe to redistribute from, and ready for the Plan 2 UI contract.

**Architecture:** Same package layout as v0.1 (`neshter/` core + thin FastAPI layer). New small modules: `neshter/progress.py` (progress callback + cooperative cancel shared by every long job) and `neshter/server/errors.py` (machine-readable `error_code`). Direction ablation becomes a projection off an orthonormal span (one basis per residual writer), which also makes the Gemma2 bake exact. Statistics move from unpaired Wald to paired McNemar/Newcombe with Holm.

**Tech Stack:** Python ≥3.11 (venv 3.14), uv, torch 2.15 CPU, transformers 5.22, gguf, fastapi, pydantic v2, pytest, httpx. New pinned dependency: `jinja2>=3.1.6,<4`.

**Spec:** `docs/superpowers/specs/2026-11-10-neshter-design.md`. Work items and their reasoning come from `.superpowers/sdd/2026-11-10-neshter-backend/audit-technical.md` (§ refs "AT"), `audit-security-product.md` ("AS") and `audit-roadmap.md` ("AR"); rulings from `progress.md`. Executors read the spec and the audit section a task cites.

## Review Focus

1. Batched hunt passes over prompts of very different lengths (left padding): the last-token residuals must equal the one-prompt-at-a-time values, otherwise every hunt silently changes. → Task 2 `test_batched_resid_matches_unbatched`.
2. A recipe with duplicate or nearly parallel directions (two hunts on the same concept): the span projection must not produce NaN and must equal removing the single direction. → Task 4 `test_duplicate_directions_equal_single`.
3. Cancel arriving while weights are baked (baked suite, export): weights must be restored bit-exactly and no hook left behind. → Task 8 `test_suite_baked_cancel_restores_weights`, Task 10 `test_save_safetensors_cancel_restores`.
4. Gemma2 post-norm weights with `γ = 1 + w = 0` entries: the γ-scaled basis must stay finite and orthonormal. → Task 5 `test_gemma2_basis_handles_zero_gamma`.
5. A GGUF or Ollama source with no license information: the card must say `license: other` / `license_name: unknown` with a warning, never crash and never claim a license. → Task 9 `test_unknown_license_card`.

- Produces:
  - `LAYER_WINDOW_FRAC = 0.8`, `MEASURE_TOP_K = 20`, `MEASURE_NEUTRAL = 8`
  - `candidate_layers(n_layers: int) -> range` returns `range(1, max(1, floor(0.8·n_layers)) + 1)`, as indices into `layer_scores` (index i = residual after layer i−1)
  - `val_accuracy(r: Tensor, train_pos: Tensor, train_neg: Tensor, val_pos: Tensor, val_neg: Tensor) -> tuple[int, int]` returning `(correct, n)`. The threshold `t` is the midpoint of the train pos/neg mean projections; a val positive is correct if its projection `> t`, a val negative if `≤ t`.
  - `@dataclass HeadMeasure(layer: int, head: int, estimated: float, signal_drop: float, neutral_kl: float)`
  - `measure_top_heads(lm, heads: list[tuple[int, int, float]], val_pos: list[str], ref_layer: int, r_ref: Tensor, m_pos: float, m_neg: float, k: int = 20, n_neutral: int = 8, progress=None, cancel=None) -> list[HeadMeasure]`, sorted by `signal_drop` descending
  - `HuntResult` becomes `(layer_scores, heads, direction, direction_layer, ref_layer: int, val_correct: int, val_n: int, val_accuracy: float, val_ci: tuple[float, float], measured: list[HeadMeasure])`. `val_consistency` is **removed**.
  - API `/api/hunt` result: `ref_layer`, `val_accuracy`, `val_ci`, `val_n`; each `heads[i]` gets `"measured": {"signal_drop", "neutral_kl"} | None`; no `val_consistency`.

Definitions (pin these exactly): `m_pos` and `m_neg` are the mean projections `resid[ref, last]·r_ref` over val positives and val negatives on the unmodified model. For head h, `m_pos_h` is the same mean with `apply(lm, [HeadAblation(l, h)])` active. Then `signal_drop = (m_pos − m_pos_h) / (m_pos − m_neg)`; 1.0 means the positives collapsed to the negative mean. For heads with `layer ≥ ref_layer`, `signal_drop = 0.0` without a forward (structural). `neutral_kl` is the mean KL over the first `n_neutral` neutral prompts, last 16 positions, with the original log-probs computed once per hunt. Re-score applies to every method.

### Task 4: Multiple directions removed by span projection (QR) in hook and bake

AT §1. Today `P_rk…P_r1` leaves the stream ⟂ r_k but not ⟂ r_1 when the directions are correlated.

**Math (both hook and bake use exactly this):**

```
R = [r_1 … r_k] ∈ ℝ^{d×k}  (unit columns, float64 for the factorization)
R = Q_full · T               (torch.linalg.qr, mode="reduced"; T upper-triangular)
keep column j  iff  |T_jj| > 1e-6 · max_i |T_ii|        → Q ∈ ℝ^{d×k'}, k' ≤ k, cast to float32
P = I − Q Qᵀ                 (projection onto span(R)^⊥; P r_i = 0 for every i)

hook  (writer output x, row vectors):  x ← x − (x Q) Qᵀ
bake  embedding rows  W_E[vocab,d]:    W_E ← W_E − (W_E Q) Qᵀ
bake  writers  W[d,in] (o_proj, down_proj): W ← W − Q (Qᵀ W);   bias b ← b − Q (Qᵀ b)
```

### Task 5: Exact Gemma2 direction ablation via γ-scaled bases

AT §2. Gemma2 adds `γ ⊙ RMSnorm(o)` with `γ = 1 + w` in float32 (`modeling_gemma2.py` `Gemma2RMSNorm.forward`; decoder lines 305–325).

**Math:**

```
Gemma2 writer:  out = γ ⊙ o / rms(o),   γ = 1 + norm.weight (float32), rms(o) a positive scalar per token
For any r:      rᵀ(γ ⊙ v) = (γ ⊙ r)ᵀ v
So out ⟂ r_i for all i   ⇔   o ⟂ (γ ⊙ r_i) for all i      (exact, any rms, any eps)

Per layer ℓ:
  S_attn,ℓ = direction_basis([γ_attn,ℓ ⊙ r_1, …, γ_attn,ℓ ⊙ r_k]),  γ_attn,ℓ = 1 + post_attention_layernorm_ℓ.weight
  S_mlp,ℓ  = direction_basis([γ_mlp,ℓ  ⊙ r_1, …]),                    γ_mlp,ℓ  = 1 + post_feedforward_layernorm_ℓ.weight
Hook at o_proj_ℓ output:    o ← o − (o S_attn,ℓ) S_attn,ℓᵀ
Hook at down_proj_ℓ output: o ← o − (o S_mlp,ℓ) S_mlp,ℓᵀ
Bake: W_o,ℓ ← W_o,ℓ − S_attn,ℓ (S_attn,ℓᵀ W_o,ℓ);  W_down,ℓ ← W_down,ℓ − S_mlp,ℓ (S_mlp,ℓᵀ W_down,ℓ)
Embedding: basis Q = direction_basis(R) (embed_scale √d is a scalar; ScaledWordEmbedding output already includes it)
lm_head is tied on Gemma2 → bake unties it (existing logic).
```

### Task 7: Paired suite statistics, "bozuk" outcome and wider detectors

AT §5c, §5d.

**Statistics (exact definitions):**

```
Per category, paired cells over the same n prompts ("pass" = check satisfied):
  a = orig pass & int pass,  b = orig pass & int fail,  c = orig fail & int pass,  d = both fail
  p_orig = (a+b)/n,  p_int = (a+c)/n,  Δ = p_int − p_orig = (c − b)/n

McNemar exact (two-sided):  n_d = b + c;  if n_d = 0 → p = 1
  p = min(1, 2 · Σ_{i=0}^{min(b,c)} C(n_d, i) · 0.5^{n_d})

Newcombe paired score interval (method 10) for Δ:
  (l1,u1) = Wilson(a+b, n),  (l2,u2) = Wilson(a+c, n)
  φ = (a·d − b·c) / sqrt((a+b)(c+d)(a+c)(b+d)),  φ = 0 if the denominator is 0
  lo = Δ − sqrt((p_int − l2)² − 2φ(p_int − l2)(u1 − p_orig) + (u1 − p_orig)²)
  hi = Δ + sqrt((u2 − p_int)² − 2φ(u2 − p_int)(p_orig − l1) + (p_orig − l1)²)
  (sqrt argument clamped at 0; lo, hi clamped to [−1, 1])

"belirsiz" = p ≥ 0.05. Target category: its own p. Non-target categories: Holm-adjusted p.
Holm: sort p ascending p_(1..m); p_adj(i) = max_{j ≤ i} min(1, (m − j + 1)·p_(j)); map back to input order.

Minimum detectable drop (shown in the summary):
  k_min = min k such that 2·0.5^k < α/m   (α = 0.05; m = number of non-target categories, at least 1)
  mde = min(1, k_min / n)                  → n = 25: 0.24 (m = 1), 0.32 (m = 4)
```
