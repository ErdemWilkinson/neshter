# 2026-11-11 Neşter 2D UI: real-model smoke test

Branch `fix/ui-smoke` (merge of Plan 2). Nothing was fixed; this lists what a first-time Turkish user sees. Screenshots
live in `D:\neshter\smoke-ui\shots\` (not committed); numbers below are their prefixes.

## Environment

- Real server: `neshter serve --no-browser`, `NESHTER_HOME=D:\neshter\smoke-ui\home`, CPU only
  (`CUDA_VISIBLE_DEVICES=`, 4 threads), `HF_HUB_OFFLINE=1`.
- Model: HuggingFaceTB/SmolLM2-135M-Instruct (30 layers x 9 heads, float32, cpu), 31.7 GB RAM machine.
- Driver: Playwright Chromium (headless), locale `tr-TR`, 1280x860 (+ 390x844 for mobile), UI language Turkish.
- Prompt: `Python'da liste sırala`. Heads K10.H2 and K15.H4 for the main flow.
- Result file written by Save: `D:\neshter\smoke-ui\out\smolsmoke` (model.safetensors, config, tokenizer, README, `recipe.nester.json`).
- The server was restarted twice between runs (ports 47912/47913); drafts persisted in `NESHTER_HOME`.

Happy path works end to end: load, heatmap, select, measure, cut, compare, save (files on disk), concept hunt, reload
with restore, leave dialog (Kaydet / Kaydetmeden çık / Vazgeç) all function. No page errors, no external requests,
no horizontal page scroll at 390 px.

Restore result: with the model fully loaded, reload shows "Önceki oturumdan kaydedilmemiş 1 kesim var: geri yükle?"
immediately, "Geri yükle" restores the cut (basket 1 item, chip "Kaydedilmemiş 1 kesim", 49-restored-after-load.png).
The leave dialog opens on header "Kapat" and "Vazgeç" closes it with the cut kept (50, 51). Exception: see Broken 1.

## Findings

### Broken

1. **Restore button clicked while the model is still loading fails.** After a reload the restore card is shown
   everywhere (Home, Model, Explore) at once. Home, "İçine bak", "Aç", and clicking "Geri yükle" while "Model yükleniyor"
   is still running gives "Kesimler geri yüklenemedi / Önce bir model yükleyin." (server 409 on `/api/recipe/check`),
   and the prompt then stays with no way forward but pressing again. Screens 44, 45 (first run).
   Expected: button disabled (or queued) until the model is ready.
   Suspect: `web/src/features/draft/RestorePrompt.tsx`.

(No other hard failure. The first server process also vanished once after the long run, without a message in its log;
could not reproduce, so it is not counted.)

### Confusing

1. **Expected 404 logs a red console error.** Every model load does `GET /api/draft/<sha>` and gets 404 when there is
   no draft ("Failed to load resource ... 404"). It is a normal "no draft" answer and should not appear as an error
   (return 200 with null, or 204). Suspect: `web/src/core/draft.ts` / `web/src/api/client.ts`.
2. **"Model meşgul: çalışan işin bitmesini bekleyin." banner during the user's own jobs** (model load, test suite, restore).
   It reads like an error and pushes all content down by ~54 px when it appears and disappears. Screens 03, 16, 44.
   Suspect: `web/src/app/BusyBanner.tsx` (shows when `isLocked`).
3. **Concept result: the 30-row layer chart comes before the heads**, so "Bulunan head'ler" sits far below the fold
   (25-concept-found.png). Suspect: `web/src/screens/Concept.tsx` (result order), `features/concept/FoundHeads.tsx`.
4. **Concept result is hard to read**: all 8 found heads show "sinyali etkileyemez"; layer scores for K24-K29 and
   "gömme" are 0.00 with no explanation; table headers are just "K" and "H". Screen 25.
   Suspect: `features/concept/FoundHeads.tsx`, `LayerChart.tsx`.
5. **Measure card is pure statistics jargon**: "KL 0,0171 ± 0,00205", "5 çekişte durdu (2 aşım)", "p > 0,05".
   No plain verdict such as "bu kesim rastgele seçimden farksız". Screen 11.
   Suspect: `features/measure/ControlStatsCard.tsx` (`measure.verdict.futility`).
6. **"Head'in çıktısı sıfırlanır (o_proj sütunları sıfır)"** is shown to every user. Screen 04.
   Suspect: `features/measure/SelectionPanel.tsx` (`measure.zero`).
7. **Header "Kapat" is ambiguous**: it shuts down the whole local server, not the tab/panel. Every screen.
   Suspect: `web/src/app/Header.tsx`.
8. **Every model row says "yavaş · RAM desteği"**, even the 590 MB model on a 31.7 GB machine (CPU-only badge logic).
   Screen 02. Suspect: `features/models/format.ts` (`models.badge.slow`).
9. **Pair answers are cut mid-sentence** ("Alternatively, you can use") with no "kesildi" notice; footer says
   "sıcaklık 0 · seed 42 · batch" ("batch" is unexplained). Screen 15. Suspect: `features/compare/PairView.tsx`.
10. **Save result card is thin**: label "Kaynak SHA-256", no size/file list; the basket still says "Kaydedilecek: 2"
    after saving, and Save has no "klasörü aç/yolu kopyala". Screen 21.
    Suspect: `features/save/ResultCard.tsx`.
11. **Stepper "2 Davranışı bul   Ağ haritası"** reads like two items numbered 2 (it is one step with two entrances).
    Suspect: `web/src/app/Stepper.tsx`.
12. **Heatmap has no axis labels or colour legend**; the "Liste" view is 270 unsorted rows (screens 07, 09).
    A cell's K/H can only be learned by hover/keyboard. Suspect: `features/map/Heatmap.tsx`, `HeatmapTable.tsx`.
13. **Compare screen does not show which cuts are being compared**; the page is mostly empty until a pair is asked
    (screen 13). Suspect: `web/src/screens/Compare.tsx`.
14. **After a reload the prompt text and heatmap are gone** while the header still says a model is loaded and the
    basket is empty until "Geri yükle" is pressed (screens 33, 41). Suspect: `web/src/screens/Explore.tsx`,
    `features/map/exploreStore.ts`.
15. **Leave dialog title is awkward Turkish**: "Ayrılıyorsunuz, kesimlerinizi daha kaydetmediniz" (natural: "henüz").
    Screen 50. Suspect: `web/src/i18n/tr.json` (`leave.title`).

### Cosmetic

1. Selection chips "K10·H2 ×" are clipped by the × button (screens 07, 31; also mobile 27).
   Suspect: `.chip` rules in `web/src/styles/app.css`.
2. On desktop, selected cells are only a thin outline until a cut exists (07); on mobile/after cut they are orange (27, 31).
   Suspect: `features/map/drawHeatmap.ts`.
3. Compare: "İkisine de sor" sits directly under the textarea with no gap, and the Hızlı/Tam control touches
   "Test setini koş" (13). Suspect: `app.css`, `features/compare/SuiteRunner.tsx`.
4. "Test seti sonuçları" caption is centred between the cards and the table; the "Dosya boyutu değişmez" card has
   no heading (17). Suspect: `features/compare/SuiteTable.tsx`, `StatCards.tsx`.
5. **No light theme and no toggle**: the UI is dark only and ignores `prefers-color-scheme` (30-light-scheme.png).
   Suspect: `web/src/styles/`.
6. Mobile 390 px: the header takes ~200 px, the model chip is clipped at the right edge, and the Compare table's
   "Bozuk cevap" column runs off-screen (27, 29). Suspect: `app/Header.tsx`, `SuiteTable.tsx`, `app.css`.
7. Disabled "Kes (geçici)" looks almost like an enabled button (04). Suspect: `features/basket/CutButton.tsx`, `app.css`.
8. "Modeli kaydet (0 kesim)" looks enabled with an empty basket (04, 33). Suspect: `features/basket/BasketPanel.tsx`.

## Counts

Broken 1, Confusing 15, Cosmetic 8.
